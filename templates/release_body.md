## DESCRIPTION

This extension allows developers to verify the integrity of their Android application using the Google Play Integrity API.

## FEATURES

- Requesting Play Integrity tokens
- Verifying tokens server-side

## DOCUMENTATION

The full documentation of the API is included in the extension asset (included files).
